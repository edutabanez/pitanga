# Pitanga

Plataforma de software para food service.

> **Identidade Visual**: Uma marca que cresce com o negócio — combinando referência brasileira com expressão visual leve, funcional e contemporânea.

---

## 🎨 Identidade Visual e Marca

Todos os assets e manuais oficiais estão organizados em [`assets/brand/`](assets/brand/):

- **Logotipo Principal**: [`logotipo_pitanga.svg`](assets/brand/logotipo_pitanga.svg)
- **Ícone / Avatar**: [`icone_pitanga.svg`](assets/brand/icone_pitanga.svg)
- **Manual de Marca (PDF v1.0)**: [`Manual_de_Marca_Pitanga.pdf`](assets/brand/Manual_de_Marca_Pitanga.pdf)

### Paleta de Cores

| Cor | HEX | RGB | Aplicação |
| --- | --- | --- | --- |
| **Verde profundo** | `#23483C` | `35, 72, 60` | Textos principais, títulos, base |
| **Verde folha** | `#568849` | `86, 136, 73` | Elementos botânicos, detalhes secundários |
| **Vermelho pitanga** | `#DE493C` | `222, 73, 60` | Acento, fruta no ponto do *i*, destaques |
| **Marfim de apoio** | `#FFF9F0` | `255, 249, 240` | Fundos claros e acolhedores |

### Tipografia

- **Logotipo**: Composição gráfica exclusiva (preservar desenho original).
- **Apoio / Interface**: **Poppins**
  - Regular (400) para textos
  - Medium (500) para rótulos e botões
  - Semibold (600) para títulos

---

## 🚀 Estrutura do Projeto

- `assets/brand/`: Identidade visual oficial (SVGs e Manual em PDF)
- `src/index.ts`: Ponto de entrada da aplicação
- `package.json`: Dependências e scripts
- `tsconfig.json`: Configurações TypeScript

## 💻 Como Executar

Instalar dependências:
```bash
npm install
```

Build e execução:
```bash
npm run build
npm start
```

Modo de desenvolvimento:
```bash
npm run dev
```
